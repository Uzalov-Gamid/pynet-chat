# PyNet: CLI Мессенджер

PyNet — это простой и удобный мессенджер, работающий через командную строку. Проект написан на Python и включает клиентскую и серверную части.

## Возможности
- Отправка и получение текстовых сообщений
- Поддержка нескольких пользователей
- Лёгкость в настройке и использовании

## Структура проекта
- `client/` — клиентская часть (файл `client.py`)
- `server/` — серверная часть (файл `server.py`)

## Установка
1. Убедитесь, что у вас установлен Python 3.9 или выше.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Uzalov-Gamid/pynet-chat.git
   ```
3. Перейдите в папку проекта:
   ```bash
   cd pynet-chat
   ```

## Запуск
### Сервер
1. Перейдите в папку `server`:
   ```bash
   cd server
   ```
2. Запустите сервер:
   ```bash
   python server.py
   ```

### Клиент
1. Перейдите в папку `client`:
   ```bash
   cd client
   ```
2. Запустите клиент:
   ```bash
   python client.py
   ```

## Пример использования
1. Запустите сервер.
2. Запустите несколько клиентов.
3. Отправляйте сообщения между клиентами через сервер.

## Протокол и тесты

Клиент и сервер передают JSON-строки в UTF-8, разделённые переводом строки.
Это сохраняет границы сообщений при объединении или разбиении TCP-пакетов.
Максимальный размер кадра — 1 МиБ. Клиент и сервер нужно обновлять вместе:
новый протокол несовместим с прежним обменом необрамлённым текстом.

Из корня репозитория:

```bash
python -m unittest discover -s tests -v
```

## Адрес подключения

Хост и порт задаются одинаково для сервера и клиента:

```bash
python server/server.py --host 127.0.0.1 --port 23456
python client/client.py --host 127.0.0.1 --port 23456
```

Запускайте команды в отдельных терминалах из корня репозитория.
Без параметров используются `127.0.0.1:12345`.
