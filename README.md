# PyNet: CLI Мессенджер

PyNet — это простой и удобный мессенджер, работающий через командную строку. Проект написан на Python и включает клиентскую и серверную части.

## Возможности
- Отправка и получение текстовых сообщений
- Поддержка нескольких пользователей
- Лёгкость в настройке и использовании

## Структура проекта
- `client/` — клиентская часть (файл `client.py`)
- `server/` — серверная часть (файл `server.py`)

## Установка
1. Убедитесь, что у вас установлен Python 3.9 или выше.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Uzalov-Gamid/PyNet.git
   ```
3. Перейдите в папку проекта:
   ```bash
   cd PyNet
   ```

## Запуск
### Сервер
1. Перейдите в папку `server`:
   ```bash
   cd server
   ```
2. Запустите сервер:
   ```bash
   python server.py
   ```

### Клиент
1. Перейдите в папку `client`:
   ```bash
   cd client
   ```
2. Запустите клиент:
   ```bash
   python client.py
   ```

## Пример использования
1. Запустите сервер.
2. Запустите несколько клиентов.
3. Отправляйте сообщения между клиентами через сервер.
